# ตัวช่วยติดตั้ง NDP Kit (สำหรับหน่วยบริการ)

ติดตั้งโดยไม่ต้องพิมพ์คำสั่งใดๆ — ดับเบิลคลิกไฟล์เดียวจบ

## วิธีใช้

### วิธี ก: คำสั่งเดียวจบ (เครื่องที่ต่ออินเทอร์เน็ตได้)

เปิด **PowerShell** แล้ววางคำสั่งนี้ ไม่ต้องคัดลอกไฟล์อะไรไปเลย

```powershell
irm https://raw.githubusercontent.com/tankitkitty/NDP-Kit/master/install/ndp-kit-setup.ps1 | iex
```

### วิธี ข: คัดลอกไฟล์ไปติดตั้ง

1. คัดลอก **ทั้งสองไฟล์** ไปไว้ในโฟลเดอร์เดียวกันบนเครื่องที่จะติดตั้ง
   - `ndp-kit-setup.bat`
   - `ndp-kit-setup.ps1`
2. ดับเบิลคลิก `ndp-kit-setup.bat`
3. เลือกเมนู `[1] ติดตั้ง หรือ อัปเดตเป็นเวอร์ชันล่าสุด`

### วิธี ค: ติดตั้งแบบออฟไลน์ (เน็ตช้าหรือไม่มีเน็ต)

ใช้ไฟล์เดียวกับวิธี ข แต่วางไฟล์อีก 2 ตัวนี้ไว้ข้างกัน ตัวช่วยจะใช้ไฟล์ในเครื่องแทนการดาวน์โหลด

- `ndp-kit.zip` — จากหน้า [Releases](https://github.com/tankitkitty/NDP-Kit/releases/latest)
- `node-v24.19.0-win-x64.zip` — จาก [nodejs.org](https://nodejs.org/dist/v24.19.0/node-v24.19.0-win-x64.zip)

---

ตัวช่วยจะทำให้เองทั้งหมด: เตรียม Node.js → ดาวน์โหลดตัวโปรแกรม → ติดตั้งลงเครื่อง →
หาพอร์ตว่าง → ตั้งให้เปิดเองตอนเข้าใช้เครื่อง → เริ่มโปรแกรม → บอก URL ที่ใช้เข้าใช้งาน

โปรแกรมจะถูกติดตั้งที่ `C:\NDPKit` เสมอ ไม่ต้องเลือกเอง

## เมนูทั้งหมด

| เมนู | ใช้ทำอะไร |
| --- | --- |
| 1 | ติดตั้งครั้งแรก **และ** อัปเดตเป็นเวอร์ชันใหม่ (ใช้เมนูเดียวกัน) |
| — | *อัปเดตยังกดได้จากในหน้าเว็บด้วย: ตั้งค่าการเชื่อมต่อ → เวอร์ชันโปรแกรม* |
| 2 | เปิดหน้าเว็บโปรแกรม |
| 3 | ดูสถานะและ log 30 บรรทัดล่าสุด (ใช้ตอนมีปัญหา) |
| 4 | เริ่ม / หยุด โปรแกรม |
| 5 | ถอนการติดตั้ง (คัดลอกโฟลเดอร์ `data` ไปเก็บไว้ที่ Desktop ให้ก่อนลบ) |

## สิ่งที่ต้องมีก่อน

**ไม่ต้องมีอะไรเลย** — ไม่ต้องลง Node.js, Git หรือ Docker และไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

ตัวช่วยจะดาวน์โหลด Node.js v24.19.0 รุ่นพกพามาไว้ที่ `C:\NDPKit\node` ให้เอง
ไม่แตะ PATH ของเครื่องและไม่ทับ Node เดิมที่อาจมีอยู่ พร้อมตรวจ SHA256 ของไฟล์
กับค่าที่ nodejs.org ประกาศไว้ ถ้าไม่ตรงจะหยุดทันที

## หลังติดตั้งเสร็จ

1. เปิดหน้าเว็บตาม URL ที่ตัวช่วยแสดง (ปกติ `http://localhost:3000`)
2. ไปเมนู **ตั้งค่าการเชื่อมต่อ** กรอก **รหัสติดตั้งครั้งแรก** ที่ตัวช่วยแสดงไว้บนหน้าจอ
   จากนั้นกรอกข้อมูล MySQL ของ HOSxP แล้วกด Save Config และ Test Connection
   > รหัสนี้กันคนอื่นในวง LAN ชิงตั้งค่าก่อนเจ้าหน้าที่ แล้วชี้ฐานข้อมูลไปเครื่องของตัวเอง
   > ใช้ได้จนกว่าจะบันทึกสำเร็จ หลังจากนั้นต้องเข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่เสมอ
   > (ถ้าหารหัสไม่เจอ ให้รันตัวช่วยแล้วเลือกเมนู 1 ใหม่ ระบบจะสุ่มรหัสใหม่ให้)
   > **host:** MySQL อยู่เครื่องเดียวกันใส่ `localhost` ได้ตามปกติ
   > ถ้าอยู่คนละเครื่องในวง LAN ใช้ IP ของเครื่องนั้น
3. เข้าสู่ระบบด้วย username/password ของเจ้าหน้าที่ในระบบ HOSxP
4. ครั้งแรกโปรแกรมจะถามว่าต้องการส่งรหัสและชื่อสถานพยาบาลไปลงทะเบียนกับผู้พัฒนาไหม
   จะส่งหรือไม่ส่งก็ใช้งานได้ครบทุกอย่างเหมือนกัน ถามครั้งเดียวไม่ถามซ้ำ

## คำถามที่พบบ่อย

**ให้เครื่องอื่นในวง LAN เข้าใช้ได้ไหม**
ได้ ใช้ URL ที่ตัวช่วยแสดงในบรรทัด "จากเครื่องอื่นใน LAN" — อาจต้องเปิด firewall ของพอร์ตนั้นก่อน

**พอร์ต 3000 ถูกโปรแกรมอื่นใช้อยู่**
ตัวช่วยจะเลี่ยงไปใช้ 3013, 3113, 3213 ให้อัตโนมัติ และจำไว้ให้ครั้งต่อไป

**อัปเดตแล้วค่าตั้งค่าหายไหม**
ไม่หาย ตัวช่วยจะยกโฟลเดอร์ `C:\NDPKit\app\data` ออกมาพักไว้ก่อนวางไฟล์ใหม่ แล้วคืนกลับให้

**โปรแกรมเปิดเองตอนเปิดเครื่องไหม**
เปิดให้ ตัวช่วยตั้ง Task Scheduler ชื่อ `NDPKit` ให้รันทุกครั้งที่เข้าใช้เครื่อง
ถ้าต้องการให้รันโดยไม่ต้องมีใครล็อกอิน ต้องตั้ง task เป็นบัญชี SYSTEM เองด้วยสิทธิ์ผู้ดูแลระบบ

**ขึ้นว่าไม่พบไฟล์ ndp-kit-setup.ps1**
คัดลอกมาไม่ครบ ต้องเอาไปทั้งสองไฟล์และวางไว้โฟลเดอร์เดียวกัน

## หมายเหตุสำหรับผู้ดูแลระบบ

ทำไมต้องแยกเป็นสองไฟล์: cmd.exe อ่านไฟล์ `.bat` ทีละไบต์ตาม code page ของ console
ข้อความภาษาไทย (UTF-8 หลายไบต์ต่อตัวอักษร) ทำให้ตัวแยกคำสั่งของ cmd เลื่อนตำแหน่งผิด
แล้วหยิบเศษคำไทยไปรันเป็นคำสั่ง จึงต้องให้ `.bat` เป็น ASCII ล้วน ทำหน้าที่แค่เรียก
PowerShell ส่วนข้อความไทยทั้งหมดอยู่ใน `.ps1` ที่ PowerShell อ่านด้วย encoding ที่ถูกต้อง

ข้อควรระวังเวลาแก้ไฟล์:
- `ndp-kit-setup.bat` ต้องเป็น **ASCII ล้วน** ห้ามมีภาษาไทยเด็ดขาด
- `ndp-kit-setup.ps1` ต้องบันทึกเป็น **UTF-8 พร้อม BOM** เพราะ Windows PowerShell 5.1
  จะอ่านไฟล์ที่ไม่มี BOM เป็นรหัส ANSI ทำให้ภาษาไทยเพี้ยนทั้งไฟล์
