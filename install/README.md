# ตัวช่วยติดตั้ง NDP Kit (สำหรับหน่วยบริการ)

ติดตั้งโดยไม่ต้องพิมพ์คำสั่งใดๆ — ดับเบิลคลิกไฟล์เดียวจบ

## วิธีใช้

1. คัดลอก **ทั้งสองไฟล์** ไปไว้ในโฟลเดอร์เดียวกันบนเครื่องที่จะติดตั้ง
   - `ndp-kit-setup.bat`
   - `ndp-kit-setup.ps1`
2. ดับเบิลคลิก `ndp-kit-setup.bat`
3. เลือกเมนู `[1] ติดตั้ง หรือ อัปเดตเป็นเวอร์ชันล่าสุด`

ตัวช่วยจะทำให้เองทั้งหมด: ตรวจ/เปิด Docker → เลือกที่เก็บโปรแกรม → หาพอร์ตว่าง →
สร้างไฟล์ตั้งค่า → ดาวน์โหลดเวอร์ชันล่าสุด → เปิดโปรแกรม → บอก URL ที่ใช้เข้าใช้งาน

## เมนูทั้งหมด

| เมนู | ใช้ทำอะไร |
| --- | --- |
| 1 | ติดตั้งครั้งแรก **และ** อัปเดตเป็นเวอร์ชันใหม่ (ใช้เมนูเดียวกัน) |
| 2 | เปิดหน้าเว็บโปรแกรม |
| 3 | ดูสถานะและ log 30 บรรทัดล่าสุด (ใช้ตอนมีปัญหา) |
| 4 | เริ่ม / หยุด โปรแกรม |
| 5 | ถอนการติดตั้ง (ไม่ลบโฟลเดอร์ `data` ที่เก็บค่าตั้งค่า) |

## สิ่งที่ต้องมีก่อน

**Docker Desktop** อย่างเดียว — ไม่ต้องลง Node.js หรือ Git
ถ้ายังไม่มี ตัวช่วยจะแจ้งและเปิดหน้าดาวน์โหลดให้

## หลังติดตั้งเสร็จ

1. เปิดหน้าเว็บตาม URL ที่ตัวช่วยแสดง (ปกติ `http://localhost:3000`)
2. ไปเมนู **ตั้งค่าการเชื่อมต่อ** กรอกข้อมูล MySQL ของ HOSxP แล้วกด Save Config และ Test Connection
   > **สำคัญ:** ถ้า MySQL อยู่**เครื่องเดียวกับ Docker** ต้องใส่ host เป็น `host.docker.internal`
   > ไม่ใช่ `localhost` (เพราะ localhost ในมุมมองของ container คือตัว container เอง)
   > ถ้า MySQL อยู่คนละเครื่องในวง LAN ใช้ IP ปกติได้เลย
3. เข้าสู่ระบบด้วย username/password ของเจ้าหน้าที่ในระบบ HOSxP

## คำถามที่พบบ่อย

**ให้เครื่องอื่นในวง LAN เข้าใช้ได้ไหม**
ได้ ใช้ URL ที่ตัวช่วยแสดงในบรรทัด "จากเครื่องอื่นใน LAN" — อาจต้องเปิด firewall ของพอร์ตนั้นก่อน

**พอร์ต 3000 ถูกโปรแกรมอื่นใช้อยู่**
ตัวช่วยจะเลี่ยงไปใช้ 3013, 3113, 3213 ให้อัตโนมัติ และจำไว้ให้ครั้งต่อไป

**อัปเดตแล้วค่าตั้งค่าหายไหม**
ไม่หาย ค่าตั้งค่าทั้งหมดอยู่ในโฟลเดอร์ `data` ซึ่งอยู่นอกตัวโปรแกรม

**ขึ้นว่าไม่พบไฟล์ ndp-kit-setup.ps1**
คัดลอกมาไม่ครบ ต้องเอาไปทั้งสองไฟล์และวางไว้โฟลเดอร์เดียวกัน

## หมายเหตุสำหรับผู้ดูแลระบบ

ทำไมต้องแยกเป็นสองไฟล์: cmd.exe อ่านไฟล์ `.bat` ทีละไบต์ตาม code page ของ console
ข้อความภาษาไทย (UTF-8 หลายไบต์ต่อตัวอักษร) ทำให้ตัวแยกคำสั่งของ cmd เลื่อนตำแหน่งผิด
แล้วหยิบเศษคำไทยไปรันเป็นคำสั่ง จึงต้องให้ `.bat` เป็น ASCII ล้วน ทำหน้าที่แค่เรียก
PowerShell ส่วนข้อความไทยทั้งหมดอยู่ใน `.ps1` ที่ PowerShell อ่านด้วย encoding ที่ถูกต้อง

ข้อควรระวังเวลาแก้ไฟล์:
- `ndp-kit-setup.bat` ต้องเป็น **ASCII ล้วน** ห้ามมีภาษาไทยเด็ดขาด
- `ndp-kit-setup.ps1` ต้องบันทึกเป็น **UTF-8 พร้อม BOM** เพราะ Windows PowerShell 5.1
  จะอ่านไฟล์ที่ไม่มี BOM เป็นรหัส ANSI ทำให้ภาษาไทยเพี้ยนทั้งไฟล์
