# ตั้งค่าช่องทางรับคำขอสร้างรายงานจากผู้ช่วย

ทำครั้งเดียว หลังจากนั้นผู้ช่วยกดปุ่ม "ส่งเข้าส่วนกลาง" ในโปรแกรมได้เลย

ภาพรวมของเส้นทาง

```
ผู้ช่วยกดปุ่มส่ง  →  Apps Script (ทำงานด้วยสิทธิ์ของคุณ)  →  ไฟล์ .json ในโฟลเดอร์ Drive
                                                                      ↓
                                        คุณเปิดหน้า "คำขอจากผู้ช่วย" แล้วกดสร้างรายงาน
```

ที่ต้องผ่าน Apps Script เพราะตัวโปรแกรมเขียนไฟล์ลง Drive เองไม่ได้ ต้องมีรหัสที่
เขียนได้ ซึ่งไม่ควรอยู่ในเครื่องผู้ช่วย สคริปต์ทำงานด้วยสิทธิ์ของเจ้าของสคริปต์
เครื่องผู้ช่วยจึงส่งได้โดยไม่มีรหัส Google อยู่ในเครื่องเลย

---

## ขั้นที่ 1 — เตรียมรหัสลับสักชุด

ใช้ชุดนี้ได้เลย (สุ่มมาให้แล้ว) หรือจะสุ่มเองก็ได้

```
5369afd8a755c4febd1085d38d202a48482128143f55658b
```

จดไว้ก่อน เดี๋ยวต้องใช้ 2 ที่ คือในสคริปต์ (ขั้น 2) และในเครื่องผู้ช่วย (ขั้น 4)
**ต้องเป็นค่าเดียวกันเป๊ะทั้งสองที่**

---

## ขั้นที่ 2 — สร้างและ deploy Apps Script

1. เปิด <https://script.google.com> ล็อกอินด้วย **บัญชีที่เป็นเจ้าของโฟลเดอร์ Drive**
2. กด **New project** (โปรเจ็คใหม่)
3. ตั้งชื่อโปรเจ็ค เช่น `NDP-Kit Report Inbox` (กดที่ "Untitled project" ด้านบนซ้าย)
4. ลบโค้ดตัวอย่างในช่อง `Code.gs` ออกให้หมด
5. เปิดไฟล์ `docs/apps-script-report-inbox.gs` ในโปรเจ็คนี้ **ก๊อปทั้งไฟล์** ไปวางแทน
6. แก้ 2 บรรทัดนี้ในโค้ดที่วางไป

   ```javascript
   var INBOX_FOLDER_ID = '1Pzv82qI4dlwtn9Gd6Jn7ygRHgsIlUI7p';   // โฟลเดอร์ Report NDP-Kit — ใส่ให้แล้ว ไม่ต้องแก้
   var SHARED_TOKEN = 'เปลี่ยนเป็นข้อความสุ่มของคุณเอง';          // <-- เปลี่ยนเป็นรหัสจากขั้นที่ 1
   ```

7. กดรูปแผ่นดิสก์ (Save) หรือ Ctrl+S
8. กด **Deploy** > **New deployment**
9. กดรูปฟันเฟืองข้าง "Select type" แล้วเลือก **Web app**
10. ตั้งค่าตามนี้ **ห้ามพลาด**

    | ช่อง | ต้องเลือก |
    | --- | --- |
    | Description | อะไรก็ได้ เช่น `v1` |
    | Execute as | **Me (อีเมลคุณ)** |
    | Who has access | **Anyone** |

    > **ต้องเป็น Anyone** เพราะเครื่องผู้ช่วยไม่ได้ล็อกอิน Google
    > ถ้าเลือก "Anyone with Google account" หรือ "Only myself" จะส่งไม่ได้
    > และโปรแกรมจะขึ้นว่า "ส่วนกลางไม่ได้ตอบเป็นข้อมูล อาจตั้งสิทธิ์ตอน deploy ไม่ถูกต้อง"

11. กด **Deploy**
12. ครั้งแรก Google จะขอสิทธิ์ — กด **Authorize access** เลือกบัญชีตัวเอง
    - ถ้าขึ้นหน้าจอ "Google hasn't verified this app" ให้กด **Advanced** แล้วกด
      **Go to NDP-Kit Report Inbox (unsafe)** — เป็นเรื่องปกติของสคริปต์ที่เขียนเอง
      ไม่ได้ส่งให้ Google ตรวจ
    - กด **Allow**
13. จะได้ **Web app URL** ลงท้ายด้วย `/exec` — **ก๊อปเก็บไว้** เดี๋ยวใช้ในขั้น 4

### ทดสอบว่า deploy สำเร็จ

เอา URL ที่ได้ไปเปิดในเบราว์เซอร์ตรงๆ ถ้าถูกต้องจะเห็นข้อความ

```json
{"ok":true,"service":"ndp-kit report inbox"}
```

ถ้าเห็นหน้าล็อกอิน Google แทน แปลว่าตั้ง **Who has access** ผิด ให้กลับไปแก้ที่
Deploy > Manage deployments > รูปดินสอ > แก้ Who has access เป็น Anyone > Deploy

> **ทุกครั้งที่แก้โค้ดสคริปต์ ต้อง deploy เวอร์ชันใหม่**
> Manage deployments > รูปดินสอ > ช่อง Version เลือก **New version** > Deploy
> ถ้าไม่ทำ URL เดิมจะยังรันโค้ดตัวเก่าอยู่

## ขั้นที่ 3 — แชร์โฟลเดอร์ให้ผู้ช่วย

จริงๆ **ผู้ช่วยไม่ต้องมีสิทธิ์อะไรใน Drive เลย** เพราะไฟล์ถูกเขียนโดย Apps Script
ที่ทำงานด้วยสิทธิ์ของคุณ ไม่ใช่ของเขา

จะแชร์ก็ต่อเมื่ออยากให้ผู้ช่วยเปิดดูเองได้ว่าไฟล์ที่ส่งไปถึงหรือยัง กรณีนั้น

1. เปิด Google Drive ไปที่โฟลเดอร์ **Version Control** > **Report NDP-Kit**
2. คลิกขวาที่โฟลเดอร์ `Report NDP-Kit` > **แชร์**
3. ใส่อีเมลผู้ช่วย เลือกสิทธิ์ **ผู้อ่าน** ก็พอ (ไม่ต้องให้เป็นผู้แก้ไข)
4. กด **ส่ง**

> **ห้ามแชร์โฟลเดอร์แม่ Version Control ให้ใครเป็นผู้แก้ไข**
> เพราะข้างในมีไฟล์โปรแกรมที่หน่วยบริการทุกแห่งดาวน์โหลดไปรัน
> ถ้ามีคนอัปไฟล์ผิดที่ ผลกระทบไปถึงทุกหน่วยพร้อมกัน

---

## ขั้นที่ 4 — ตั้งค่าเครื่องผู้ช่วย

**ไม่ต้องทำอะไร** — URL กับรหัสใส่ไว้ในตัวโปรแกรมแล้ว (ดู `lib/reports/submit.ts`)
ผู้ช่วยแค่ลงโปรแกรมเวอร์ชันที่มีของพวกนี้ แล้วเปิดโหมดผู้ดูแลก็กดส่งได้เลย

### ถ้าวันหนึ่งต้องเปลี่ยน URL หรือรหัส

เช่น deploy สคริปต์ใหม่แล้วได้ URL ใหม่ และไม่อยากรอปล่อยเวอร์ชัน ให้สร้างไฟล์
**`C:\NDP-Kit\app\data\report-inbox.json`** ที่เครื่องผู้ช่วย

```json
{
  "url": "URL ใหม่ที่ลงท้าย /exec",
  "token": "รหัสใหม่ที่ตรงกับ SHARED_TOKEN ในสคริปต์"
}
```

แล้วปิดเปิดโปรแกรมหนึ่งครั้ง ค่าในไฟล์นี้จะใช้แทนค่าที่อยู่ในโค้ด

> **ห้ามตั้งค่าใน `start.cmd`** เพราะตัวช่วยติดตั้งเขียนไฟล์นั้นทับใหม่ทุกครั้งที่
> อัปเดตเวอร์ชัน ค่าที่ตั้งไว้จะหายเงียบๆ ส่วนโฟลเดอร์ `data` ตัวช่วยติดตั้งยก
> ออกมาพักแล้วคืนกลับให้เสมอ ตั้งที่นี่จึงอยู่ถาวร

---

## ขั้นที่ 5 — ลองใช้จริง

**ที่เครื่องผู้ช่วย**

1. เข้าโปรแกรม กดที่**ชื่อตัวเองมุมล่างซ้าย**
2. กรอกรหัส `NDP-Kit` — ป้ายชื่อจะขึ้นแท็ก "ผู้ดูแล" สีเหลือง
3. ไปเมนู **รายงาน** > **+ สร้างรายงานใหม่** เขียน query แล้วกด **รันรายงาน** ดูผลก่อน
4. กด **บันทึกรายงาน**
5. ในรายการ กด **ส่งเข้าส่วนกลาง**

**ที่เครื่องคุณ**

1. เข้าโปรแกรม กดชื่อตัวเอง กรอกรหัส `NDP-Kit`
2. ไปเมนู **รายงาน** > **คำขอจากผู้ช่วย**
3. เห็นคำขอที่ส่งมา กดดูรายละเอียด เลือกหมวด แล้วกด **นำไปสร้างรายงานในระบบ**
4. ปล่อยเวอร์ชันใหม่ (`.\scripts\release.ps1`) แล้วอัปไฟล์ขึ้น Drive

## เวลามีปัญหา

| อาการ | สาเหตุที่พบบ่อย |
| --- | --- |
| "เครื่องนี้ยังไม่ได้ตั้งค่าที่อยู่ส่วนกลาง" | ยังไม่มีไฟล์ `data\report-inbox.json` หรือ url/token ว่าง — ตรวจว่าสร้างถูกโฟลเดอร์และปิดเปิดโปรแกรมแล้ว |
| "ส่วนกลางไม่ได้ตอบเป็นข้อมูล อาจตั้งสิทธิ์ตอน deploy ไม่ถูกต้อง" | Who has access ไม่ได้เป็น Anyone |
| "รหัสไม่ถูกต้อง" (ตอนส่ง) | `token` ในไฟล์ไม่ตรงกับ `SHARED_TOKEN` ในสคริปต์ |
| "ส่วนกลางตอบกลับรหัส 404" | URL ผิด หรือลบ deployment ไปแล้ว |
| แก้สคริปต์แล้วยังทำงานแบบเดิม | ลืม deploy เวอร์ชันใหม่ (Manage deployments > Version: New version) |
| ส่งสำเร็จแต่ไม่เห็นในหน้าคำขอ | `INBOX_FOLDER_ID` ในสคริปต์ชี้คนละโฟลเดอร์กับที่โปรแกรมอ่าน (`lib/reports/inbox.ts`) |

## ขอบเขตของรหัสลับ

รหัส `NDP-Kit` ที่ใช้เปิดเมนู **ติดไปกับโปรแกรมทุกเครื่อง** ใครแกะไฟล์โปรแกรมดูก็เห็น
มันมีไว้ซ่อนเมนูไม่ให้เจ้าหน้าที่ทั่วไปเผลอกด **ไม่ใช่การกันคนที่ตั้งใจจะเข้า**

ส่วน `SHARED_TOKEN` กันคนที่บังเอิญเจอ URL แล้วยิงข้อมูลขยะเข้ามา ความเสียหาย
สูงสุดถ้าหลุดคือมีไฟล์ขยะในโฟลเดอร์ ซึ่งลบทิ้งได้ ไม่กระทบข้อมูลผู้ป่วยหรือไฟล์โปรแกรม
